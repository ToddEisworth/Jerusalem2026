    1.3 Pseudopowers

    Representability

    Let \(\lambda\) be a singular cardinal. A cardinal \(\kappa\) is representable at \(\lambda\) if there are a set \(A\) and an ideal \(J\) such that

    • \(A\) is cofinal in \(\lambda\cap\operatorname{Reg}\)
    • \(|A|=\operatorname{cf}(\lambda)\)
    • \(J\) is an ideal on \(A\) extending the bounded ideal \(J^{\mathrm{bd}}_A\)
    • \(\kappa = \operatorname{tcf}\left(\prod A/J\right)\)

    The pseudopower function

    Now we define

    \[\operatorname{PP}(\lambda)=\{\kappa:\kappa\text{ is representable at }\lambda\},\]

    and

    \[\operatorname{pp}(\lambda)=\sup\operatorname{PP}(\lambda).\]

    \(\operatorname{pp}(\lambda)\) is called the pseudopower of \(\lambda\) and it functions as a pcf-theoretic version of the gimel function \(\gimel(\lambda)=\lambda^{\operatorname{cf}(\lambda)}\).

    Note that \(\lambda^+\) is representable at \(\lambda\) by Shelah's theorem on the existence of scales, so \(\operatorname{pp}(\lambda)\geq\lambda^+\).

    Combinatorial Significance

    What does the cardinal \(\operatorname{pp}(\lambda)\) really mean?

    Given \(\delta<\lambda\) let \(R(\delta,\lambda)\) be the collection of regular cardinals in the interval \((\delta,\lambda)\). If \(\operatorname{cf}(\lambda)\leq\delta\) then any subset \(A\) of \(R(\delta,\lambda)\) of cardinality \(\operatorname{cf}(\lambda)\) will be progressive, and hence \(\max\operatorname{pcf}(A)\) will exist and it is equal to the pointwise cofinality of the product \(\prod A\).

    If we define

    \[\eta(\delta)=\sup\{\max\operatorname{pcf}(A):A\subseteq R(\delta,\lambda)\text{ and }|A|=\operatorname{cf}(\lambda)\}\]

    then \(\delta\leq\varepsilon<\lambda\) implies \(\eta(\varepsilon)\leq\eta(\delta)\) and hence there is a \(\delta<\lambda\) for which the value of \(\eta(\delta)\) achieves its minimum. We claim that \(\operatorname{pp}(\lambda)\) is precisely this stabilizing value \(\eta(\delta)\), that is, that

    \[\operatorname{pp}(\lambda)=\min\{\sup\{\max\operatorname{pcf}(A): A\subseteq R(\delta,\lambda)\text{ and }|A|=\operatorname{cf}(\lambda)\}:\delta<\lambda\}.\]

    Note that in the above equation, the set \(A\) may very well be bounded below \(\lambda\). The point is that \(\lambda\) has a tail so that any set \(A\) of \(\operatorname{cf}(\lambda)\) regular cardinals drawn from that tail will satisfy \(\max\operatorname{pcf}(A)\leq\operatorname{pp}(\lambda)\).

    The inequality \(\leq\) should be clear: if \(\kappa\) is representable at \(\lambda\) as \(\prod A/J\) for \(A\) and \(J\) as in the definition, then for any \(\delta<\lambda\) we may discard the bounded set \(A\cap \delta+1\) (as it is \(J\)) and see that \(\kappa\) is in \(\operatorname{pcf}(A\setminus(\delta+1))\).

    For the reverse inequality, put \(\kappa=\operatorname{cf}(\lambda)\) and \(P=\operatorname{pp}(\lambda)\). Suppose toward a contradiction that \(\eta(\delta)>P\) for every \(\kappa\leq\delta<\lambda\).

    Choose an increasing sequence \(\langle\delta_i:i<\kappa\rangle\) cofinal in \(\lambda\), with \(\delta_0\geq\kappa\). For each \(i<\kappa\), choose \(A_i\subseteq R(\delta_i,\lambda)\) such that

    \[|A_i|=\kappa\qquad\text{and}\qquad\max\operatorname{pcf}(A_i)>P.\]

    Let \(A=\bigcup_{i<\kappa}A_i\). Then \(A\) is progressive, \(|A|=\kappa\), and \(\sup A=\lambda\). Moreover, for every \(\delta<\lambda\),

    \[\max\operatorname{pcf}\bigl(A\setminus(\delta+1)\bigr)>P,\]

    since some \(A_i\) is contained in \(A\setminus(\delta+1)\).

    These tail maxima are nonincreasing as \(\delta\) increases, so they eventually stabilize. Discarding a bounded initial segment of \(A\), we may therefore assume that

    \[\eta=\max\operatorname{pcf}(A)=\max\operatorname{pcf}\bigl(A\setminus(\delta+1)\bigr)>P\]

    for every \(\delta<\lambda\).

    Let

    \[I=J_{<\eta}[A]=\{B\subseteq A:\operatorname{pcf}(B)\subseteq\eta\}.\]

    By the basic pcf theorem, there is a \(<_I\)-increasing cofinal sequence \(\langle f_\alpha:\alpha<\chi\rangle\) in \(\prod A\).

    Let \(J\) be the ideal generated by \(I\) together with the bounded subsets of \(A\). This ideal is proper: otherwise, for some \(\delta<\lambda\) we would have

    \[A\setminus(\delta+1)\in I,\]

    contradicting the fact that this tail has maximum possible cofinality \(\eta\).

    Since \(I\subseteq J\), the same sequence remains \(<_J\)-increasing and cofinal. Consequently,

    \[\operatorname{tcf}\left(\prod A/J\right)=\eta.\]

    But \(|A|=\operatorname{cf}(\lambda)\) and \(J\) contains every bounded subset of \(A\), so this witnesses that \(\chi\) is representable at \(\lambda\). Thus

    \[\eta\leq\operatorname{pp}(\lambda)=P,\]

    a contradiction.

    Therefore \(\eta(\delta)\leq\operatorname{pp}(\lambda)\) for some \(\delta<\lambda\). Together with the preceding inequality, this proves the claimed characterization.

    \[\tag*{$\square$}\]

    Note

    If \(\lambda\) is not a fixed point, then for all sufficiently large \(\delta<\lambda\) the set \(R(\delta,\lambda)\) is a progressive interval of regular cardinals, and we can apply pcf analysis in this setting. This is one reason we know so much more about cardinal arithmetic at non-fixed points, and why getting information when \(\lambda=\aleph_\lambda\) is more difficult.
