# 1.9 The cov vs pp problem

We have seen two theorems tying together covering numbers and pseudopowers.

Shelah's cov vs. pp theorem says that there is an exact match, provided we are allowed to use countable unions in our attempts to cover:

!!! Theorem
    If $\aleph_0<\sigma=\operatorname{cf}(\sigma)\leq\operatorname{cf}(\lambda)<\theta<\lambda$ with $\theta\leq\kappa\leq\lambda$ then

    $$\operatorname{cov}(\lambda,\kappa,\theta,\sigma)+\lambda=\sup_{\substack{\kappa\leq\mu\leq\lambda\\\sigma\leq\operatorname{cf}(\mu)<\theta}}\operatorname{pp}_{\Gamma(\theta,\sigma)}(\mu)+\lambda.$$


If we drop that requirement, then we have an exact match when dealing with cardinals that are not fixed points:

!!! theorem
    Suppose $\lambda$ is singular, $\lambda<\aleph_\lambda$, and $\operatorname{cf}(\lambda)\leq\theta<\lambda$. Then

    $$\operatorname{cov}(\lambda,\lambda,\theta^+,2)=\operatorname{pp}_\theta(\lambda).$$
    
    In particular,

    $$\operatorname{cov}\bigl(\lambda,\lambda,\operatorname{cf}(\lambda)^+,2\bigr)=\operatorname{pp}(\lambda).$$
